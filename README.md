1. Projektin idea
Projektin ideana oli luoda kahden renkaan varassa itsetasapainotteleva robotti. Se pystyisi laskemaan missa asennossa se on kiihtyvyysanturin avulla ja stabilisoimaan itsensä kaatumatta maahan. Robotin tulisi pyörittää renkaita kallistumisen suuntaan korjatakseen asentonsa. Robotti pistettäisiin päälle napin painalluksella jolloin kiihtyvyysanturi alkaisi syöttämään lukuja arduinolle sen asennosta ja arduino ohjaisi renkaita pyörimään syötteen perusteella. Mahdollisesti sitä myös pystyisi ohjata kauko-ohjauksella.
